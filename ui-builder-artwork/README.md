# Project-owned Jetcaster benchmark artwork

This dependency-only module owns the two offline raster assets used by the Jetcaster benchmark's
reference, document renderer, generated Compose fixture, and structured-SVG recorder. The artwork
is original procedural test imagery generated by this repository; it does not copy or claim the
license of upstream podcast cover art.

`scripts/generate-ui-builder-artwork.mjs` deterministically produces normalized 512×512 RGBA PNGs.
The checked-in `manifest-v1.json` records each asset key, source variant, Apache-2.0 license scope,
encoded PNG SHA-256, and decoded RGBA SHA-256. Run the generator with `--check` or execute
`:ui-builder-artwork:check` to detect byte, manifest, fixture-key, provenance, or lane-binding drift.

The module deliberately exposes only exact asset-key lookup. It has no URL, RSS, network, or
mutable-feed fallback.
